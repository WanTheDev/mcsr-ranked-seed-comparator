# Seed Comparator
A simple tool for finding other completions on seeds you have played in MCSR Ranked.

## Usage
Make sure you have Python installed.
Using the VSCode command line allows you to click links instead of copy/pasting them.
Download the repo & open the command line inside the folder, then input:
```bash
pip install requests rich
python seed_comparator.py
```
After you run the script, input your username.
This will go through all of your matches and showcase other completions of the same seed.
